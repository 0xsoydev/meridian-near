# Demo script

Target 2:45. Human voice. One take per beat, cut on the action.

1. **0:00 — the problem.** Idle API credits expire. Agents need inference and have no wallet a human can trust with a card. Say both in one breath over the landing page.
2. **0:15 — the contract.** `core.<team>.near` on NearBlocks: wallets, caps, markets, rollups. One sentence each.
3. **0:30 — an agent gets a key.** In the terminal, run the device call. The QR appears; scan it on the phone; fund $10 and approve $5/day. The agent prints its key and never sees the wallet.
4. **0:55 — inference.** The agent streams a completion. Show `X-Meridian-Paid-From` and the float in `/me`. The router pulled from the owner's wallet.
5. **1:10 — the limit.** The agent hits $5. The 403 carries the approval link; the human raises it; the next request goes through.
6. **1:30 — spot.** Buy 1 MTok on `/trade`, sell half into the book, show the fills and the tape.
7. **1:50 — perps.** Open a long, add margin, close. Point at the index built from the rollups, not an oracle feed.
8. **2:10 — receipts.** `/receipts` recomputes the index from the on-chain rollups; a NEAR AI proof shows its signer.
9. **2:25 — money out.** A seller's payout in USDC, and the 1Click quote back to another chain.
10. **2:40 — close.** One line on what NEAR makes possible: USDC wallets, on-chain limits, cross-chain settlement.
